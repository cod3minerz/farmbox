# Hashpix Automation

Локальная панель управления Android-устройствами. Сайт и сервер запускаются вместе на компьютере, к которому подключены телефоны.

## Быстрый запуск на Windows и macOS

1. Установите [Node.js LTS](https://nodejs.org/en/download/) версии 22 или новее.
2. На странице репозитория GitHub нажмите **Code → Download ZIP** и распакуйте архив. Откройте папку с файлом `package.json` в Терминале на macOS или в **Командной строке (cmd)** на Windows.
3. Выполните команду:

   ```sh
   npm start
   ```

4. Когда в терминале появится заставка **HASHPIX**, откройте указанный под ней адрес в Chrome или Edge. По умолчанию это [127.0.0.1:3000](http://127.0.0.1:3000). Включите отладку по USB в параметрах разработчика на телефоне, подключите его кабелем и разрешите отладку в появившемся запросе. Телефон появится на стене устройств.

При первом запуске нужен интернет. Команда устанавливает зависимости проекта и скачивает ADB и scrcpy в папку проекта. Следующие запуски используют скачанные файлы. Редактор кода, Git и Android Studio не нужны.

Оставьте терминал открытым, пока пользуетесь панелью. Чтобы остановить её, нажмите **Ctrl+C**. Для следующего запуска выполните ту же команду.

На Windows для некоторых моделей может понадобиться [USB-драйвер производителя](https://developer.android.com/studio/run/oem-usb). Для снимков виртуального экрана отдельно установите FFmpeg и добавьте его в PATH или укажите путь в `HASHPIX_FFMPEG_PATH`.

## Разработка

[План платформы](docs/platform-plan.md) и [дизайн-система](DESIGN.md).

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Стена показывает подключённые Android-устройства и их виртуальные экраны. Кнопка «Добавить экран» загружает список приложений с телефона, включая доступные копии MIUI. Графы, результаты симуляций и очередь пока хранятся в браузере. Локальное видеопревью работает в текущей вкладке.

Для работы с телефоном установите [Android SDK Platform Tools](https://developer.android.com/tools/releases/platform-tools) и добавьте ADB в PATH. Также поддерживаются стандартные переменные Android SDK, локальная папка `.engine-tools/platform-tools` и абсолютный путь `HASHPIX_ADB_PATH`. Подключите телефон по USB, включите отладку и подтвердите запрос на устройстве. Просмотр показывает H.264 через scrcpy и поддерживает тап, свайп, «Домой» и «Назад». Для просмотра используйте Chrome или Edge с WebCodecs. Поместите [сервер scrcpy 3.3.4](https://github.com/Genymobile/scrcpy/releases/download/v3.3.4/scrcpy-server-v3.3.4) в `.engine-tools/scrcpy-server-v3.3.4` или укажите абсолютный путь в `HASHPIX_SCRCPY_SERVER`. Для снимков виртуального экрана нужен FFmpeg в PATH или абсолютный путь `HASHPIX_FFMPEG_PATH`. При запросе MIUI на запуск копии разблокируйте телефон и подтвердите запуск.

В «Автоматизациях» кнопка «Шаблон жестов» создаёт граф со свайпом, случайной паузой от 5 до 15 секунд и двойным тапом в цикле. Координаты задаются в процентах или записываются с изображения. Кнопка «Экраны» задаёт один или несколько адресатов. «Запустить» в инспекторе отправляет граф выбранным экранам, а «Симуляция» проверяет маршрут без команд на устройство. Журнал в инспекторе показывает текущие события по каждому экрану. История серверных запусков хранится в `.engine-data`. [План движка](docs/engine-plan.md).

```sh
npm run typecheck
npm run lint
npm run build
```
